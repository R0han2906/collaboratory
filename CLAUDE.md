# Collaboratory — Claude Code Instructions

## What This Project Is
Collaboratory is an AI-powered project discovery and team 
collaboration platform for developers.

It helps developers find resume-worthy project ideas, 
match with teammates, and track project progress.

## Architecture
- Frontend: Next.js 14+ (App Router) in /frontend
- Backend: FastAPI (Python) in /backend
- Database: PostgreSQL
- Cache: Redis
- AI Layer: OmniRoute routing to Groq/Ollama
- Auth: NextAuth.js
- Styling: Tailwind CSS + shadcn/ui
